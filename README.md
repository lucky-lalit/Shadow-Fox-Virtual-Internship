# Shadow-Fox Virtual Internship

This repository contains the work completed during the **Shadow-Fox Virtual Internship**, focusing on real-world data science and analytics tasks. The internship emphasizes practical learning through hands-on projects involving data analysis, visualization, and basic machine learning.

---

## 📁 Repository Structure

| Task | Description |
|-----|-------------|
| TASK 1 – Boston House Price Prediction | Predicting house prices using data analysis and machine learning techniques |
| TASK 2 – Store Sales and Profit Analysis | Analyzing sales and profit data to extract meaningful business insights |

---

## 🚀 Internship Objective

The main objectives of this internship were:
- To gain practical experience with real datasets  
- To improve Python programming and data analysis skills  
- To understand data preprocessing, visualization, and modeling  
- To apply analytical thinking to solve business problems  

---

## 🧠 Task Details

### TASK 1: Boston House Price Prediction
- Data exploration and cleaning  
- Feature selection  
- Model building and evaluation  

**Technologies Used:**  
Python, Pandas, NumPy, Scikit-learn, Matplotlib

---

### TASK 2: Store Sales and Profit Analysis
- Exploratory Data Analysis (EDA)  
- Sales and profit trend analysis  
- Business insight generation  

**Technologies Used:**  
Python, Pandas, Matplotlib, Seaborn
