# Boston Housing Prediction

Model to predict house prices using the Boston Housing dataset.

## Setup
1. Install requirements:
   ```
   pip install -r requirements.txt
   ```

## Usage
- Run `python train.py` to train the model.
- Run `python predict.py` to test it.
- Run `python visualize_results.py` for plots.

Files:
- `train.py`: Model training with GridSearchCV
- `predict.py`: Script for predictions
- `preprocess.py`: Data cleaning
- `visualize_results.py`: Plotting results
